agent.ts 
import { ProceedGate } from '@proceedgate/sdk';

const gate = new ProceedGate({ apiKey: process.env.PROCEEDGATE_KEY });

// Before each agent action
const check = await gate.check({
  user_id: 'agent-1',
  action: 'web_search',
  cost: 1,  // 1 credit per call

if (!check.allowed) {
  console.log(`🚫 Blocked: ${check.error}`);
  return;
}

Frequently Asked Questions

Can't find your answer? Reach out — we typically reply within 2 hours.

How does ProceedGate detect retry storms?
ProceedGate tracks request hashes per agent per minute. If more than 10 identical requests arrive within 60 seconds (configurable), it blocks subsequent calls and triggers an alert. This catches the most common failure mode — infinite retry loops from failed API calls.
Will it slow down my agents?
No. ProceedGate runs on Cloudflare's edge network (300+ locations). Each cost check resolves in under 50ms. For comparison, a typical OpenAI API call takes 500–3000ms.
Can I try it before paying?
Yes — every plan includes a 14-day free trial with full features. No credit card required. You can also start in LOG_ONLY mode to observe what ProceedGate would block without actually blocking anything.
What happens when an agent hits its budget?
The gate returns a blocked response with a proceed_token flow. The agent receives a clear "budget exceeded" signal. You also get a webhook notification. You can then manually approve more spend via the dashboard or API — no runaway charges.
Which agent frameworks are supported?
Any framework that can make HTTP calls. We provide a Node.js SDK for native integration, plus an MCP server for AI-native tool access. Works with LangChain, AutoGPT, Apify, CrewAI, and custom agents. REST API available for non-Node environments.
How is this different from just setting API rate limits?
Rate limits cap requests per second — they don't track cost. An agent can stay under rate limits while spending $500/hour on expensive calls. ProceedGate tracks actual spend, detects cost anomalies, and gives you budget-based (not rate-based) control.
